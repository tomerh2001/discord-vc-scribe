🎙 VC Scribe

A private, self-hosted Discord bot that sits in a voice channel 24/7 and writes down who said what.

@Tomer okay so culvert reset is tomorrow, are we running it early?

🔇 Deafened — transcription paused. Undeafen me to resume.

⬅️ @Dana left the call.

Features

🎙️ Exact attribution

Discord sends one audio stream per speaker — every message starts with @who-said-it. No diarization guesswork.

📌 Assigned, not invited

/scribe assign parks it in a VC until you unassign it. Survives restarts, auto-reconnects.

🔇 Deafen = pause

Server-deafen the bot to stop transcription instantly. Undeafen to resume. Visible to everyone in the call.

➡️ Full call log

Joins and leaves are logged alongside speech, so the transcript reads like the call happened.

🏠 100% on your hardware

Local Whisper (faster-whisper via speaches). Audio never leaves your server.

🔒 Private by design

Built to run with Discord's "Public Bot" switched off — nobody but you can add it anywhere.

Up and running in three steps

  1. Create a Discord app with Public Bot unchecked, copy the token.
  2. docker compose up -d on your home server — bot + local Whisper, one command.
  3. /scribe assign a voice channel and a log channel. Done.
git clone https://github.com/tomerh2001/discord-vc-scribe.git
cd discord-vc-scribe
cp .env.example .env   # paste your DISCORD_TOKEN
docker compose up -d --build
